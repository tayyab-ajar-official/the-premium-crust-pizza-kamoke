# Premium Crust website

GitHub Pages par lagane ke steps:

1. GitHub par nayi repository banayein (misal: `premium-crust`).
2. Is folder ki saari files (index.html, favicon.ico, assets/, .nojekyll) upload karein.
3. Repository mein Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Kuch minute baad site `https://<username>.github.io/premium-crust/` par live hogi.

Logo: `assets/logo.jpg` (favicon aur tab icon `assets/favicon-*.png` aur `favicon.ico`).
Photos badalne ke liye `assets/slide-*.jpg` replace karein ya `index.html` mein naye `<figure class="slide">` add karein.
